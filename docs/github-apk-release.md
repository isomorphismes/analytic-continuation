# GitHub APK release boundary

GitHub prereleases open directly into the live holomorphic-random meromorphic explorer. The direct-install APK contains no generated movies, and the launcher resolves to `ExplorerActivity`.

Before publication, CI builds all native ABIs, verifies the random-holomorphic direction worker and the absence of migrated lasso/disc machinery, installs the exact APK in an Android emulator, captures a visibly rendered EGL/OpenGL ES frame, exercises the flowing field and direct zero/pole interaction, and requires the resulting native interaction log. Publication depends on that emulator job succeeding.

Development APKs keep the repository's old public sideload signing identity and `.lasso.dev` debug package suffix solely so corrected builds can update older test installs in place. Those legacy names do not indicate a lasso mode. Google Play uses the permanent package ID `org.isomorphisms.analyticcontinuation` and a separate private upload key.

Never use a repository test/sideload key for Google Play production signing.
